# 📖 Project Overview

This project analyzes **Air Quality Index (AQI)** data to uncover pollution trends, compare pollutant concentrations, and build interactive dashboards that help users understand air quality across different states and months.

The project demonstrates the complete **Data Analytics Workflow** from raw data to business insights.

---

# 🎯 Objectives

- 🌍 Analyze Air Quality Index (AQI)
- 📊 Monitor Monthly AQI Trends
- 🏙 Compare Pollution Levels Across States
- 🌫 Analyze Pollutants (PM2.5, PM10, CO, NO₂, SO₂, O₃)
- 📈 Build Interactive Tableau Dashboard
- 📉 Create Business Intelligence Visualizations
- 💡 Generate Actionable Insights
