# 📖 About the Project

This project presents an **interactive Air Quality Index (AQI) Dashboard** developed using **Python**, **Tableau**, **SQL**, and **Power BI**.

The dashboard analyzes pollution levels across different states and months, providing meaningful insights into air quality trends and pollutant concentrations.
